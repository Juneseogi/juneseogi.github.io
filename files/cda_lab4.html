Strategies in model selecton

모형 선택에서는 적합도와 해석 가능한 단순성의 균형이 필요하다. 연구가설상 필요한 변수는 자동선택 결과와 무관하게 포함하고, 상호작용을 넣을 때는 관련 주효과도 유지한다. 강하게 상관된 설명변수의 중요도를 개별 \(P\)값만으로 판단해서는 안 된다.

[Example : Horseshoe Crabs]

  • Response outcome : whether a female crab has any other satellites(1=yes, 0=no).
  • Explanatory variables : female crab’s color(4 categories), spine condition(3 categories), weight, and shell width.
Model :

\(\displaystyle logit(P(Y=1)) = \alpha + \beta_1 weight + \beta_2 width + \beta_3 c_2 + \beta_4 c_3 + \beta_5 c_4 + \beta_6 s_2 + \beta_7 s_3\)

Stepwise Variable Selection Algorithms/ AIC and Bias&Variance tradeoff

AIC는 \(-2\ell+2k\)로 적합도와 모수 수를 함께 고려하며, 값이 작은 모형을 선호한다. AIC 차이는 유의성 검정이 아니며 단계적 선택은 표본 변화에 민감하다. 선택 결과는 이론적 타당성과 모형의 안정성을 함께 고려해 해석한다.

  • Forward Selection: add terms sequentially until further additions do not improve the fit.
  • Backward elimination: start with a complex model and sequentially remove terms.
  • A \(purposeful\) \(selection\) process proposed by Hosmer et al. (2013)
#According to Table 5.1, C+W model is selected.
fit <- glm(y ~ width + factor(color), family = binomial, data = Crabs)

Model Checking : Goodness of fit

잔차 deviance는 적합모형과 포화모형의 차이를 나타낸다. grouped binomial 자료에서는 전역 적합도 검정이 유용할 수 있다. 연속형 설명변수가 있는 ungrouped 0/1 자료에서는 단순한 deviance 카이제곱 근사가 부적절할 수 있으므로 잔차와 영향점을 함께 확인한다.

Goodness of fit for Marijuana use survey

Marijuana <- read.table("https://raw.githubusercontent.com/alanagresti/categorical-data/master/Marijuana.dat", header = TRUE)
fit <- glm(yes/(yes + no) ~ gender + race, weights = yes + no, family = binomial, data = Marijuana)
fit$deviance # residual deviance goodness-of-fit statitsic
[1] 0.05798151
fit$df.residual # residual df
[1] 1
1-pchisq(fit$deviance, fit$df.residual) # p-value for deviance goodness-of-fit test
[1] 0.8097152
fitted(fit)
        1         2         3         4 
0.4045330 0.4541297 0.3035713 0.3480244 
n = Marijuana$yes + Marijuana$no
fit.yes <- n*fitted(fit); fit.no <- n*(1-fitted(fit))
attach(Marijuana)
data.frame(race, gender, yes, fit.yes, no, fit.no)


Infinite estimates in logistic regression

완전분리나 준완전분리가 있으면 유한한 최대우도추정치가 존재하지 않는다. 소프트웨어가 큰 계수와 표준오차를 출력해도 Wald 검정은 신뢰하기 어렵다. 분리 여부를 진단하고 profile likelihood나 정확 방법을 고려한다.

Complete and quasi-complete separation (Perfect discrimination)

  • Complete separation : observations are completely separated at the point of separation.
  • Quasi-complete separation : observations of both type occur at the point of separation in the \(x\) values.

[Example : Toys example with infinite estimated effect]

Sparse data and infinite effect with categorical predictors

희소 분할표의 0 셀은 대개 표본에서 우연히 관측되지 않은 sampling zero이다. 모형 적합 전후에 교차표, 수렴경고, 큰 계수와 표준오차를 확인해야 한다.

[Example : Risk factors for endometrial cancer grade]

  • Response variable : histology grade (HG, 0 = low, 1 = high)
  • Explanatory variables :
    • \(x_1\) = neovasculation (NV, 1 = present, 0 = absent)
    • \(x_2\) = pulsatility index of arteria uterina (PI, 0 to 49)
    • \(x_3\) = endometrium height (EH, 0.27 to 3.61)
Consider the main effect model,

\(logit(P(Y=1)) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3\)

Endo <- read.table("https://raw.githubusercontent.com/alanagresti/categorical-data/master/Endometrial.dat", header = T)
Endo
xtabs(~ NV + HG, data = Endo) # quasi-complete separation
   HG
NV   0  1
  0 49 17
  1  0 13

For all 13 patients having \(x_1 = 1\), the outcome is \(y = 1\). Therefore, the data exhibit quasi-complete separation. Then, \(\hat{\beta}_1 = \infty\).

fit <- glm(HG ~ NV + PI + EH, family = binomial, data = Endo)

Alternative link functions

identity link의 선형확률모형은 계수를 위험차처럼 해석할 수 있지만 예측확률이 \([0,1]\)을 벗어날 수 있다. logit은 확률범위를 유지하며 오즈비 해석이 가능하고, probit은 정규 잠재변수의 임계값 모형이다. logit과 probit의 계수는 척도가 달라 직접 비교할 수 없다.

\(P(Y=1) = \alpha + \beta_1 x_1 + \cdots + \beta_p x_p\)

(2) Probit model

Model :

\(probit(P(Y=1)) = \alpha + \beta_1 x_1 + \cdots + \beta_p x_p\)

Link function : probit link which transforms \(P(Y=1)\) to the standard normal \(z-\)score at which the left-tail probability equals \(P(Y=1)\).   (ex : \(probit(0.05) = -1.645\), \(probit(0.50) = 0\))

Suppose that a latent variable \(y^*\) exists such that the observed binary variable \(y=0\) if \(y^* \le \tau\) and \(y=1\) if \(y^* > \tau\) for some unknown threshold \(\tau\). \[ y^* = \alpha + \beta_1 x_1 + \cdots + \beta_p x_p + \epsilon \]

[Example : Snoring and heart disease]

Consider \(y^*\) as a latent continuous measure of heart disease.
