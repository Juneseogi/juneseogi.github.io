반응범주가 \(J>2\)이면 범주별 도수를 다항분포로 모형화한다. 명목형 반응에는 baseline-category logit, 순서형 반응에는 누적로짓이나 인접범주로짓을 주로 사용한다. 순서형 자료에 명목형 모형을 적용하면 순서정보를 사용하지 못한다.

Now, we study models for categorical responses with more than two categories.

The multicategory models assume that the counts in the categories of \(Y\) have a multinomial distribution.

  • Models for nominal responses : Baseline logit model, Discrete choice model
  • Models for ordinal responses : Cumulative logit model, Adjacent categories model, etc.


Baseline-category logits

\(J\)개 범주 중 하나를 기준범주로 정하면 \(J-1\)개의 로짓식을 동시에 적합한다. \(\exp(\beta_j)\)는 \(x\)가 1 증가할 때 범주 \(j\) 대 기준범주의 오즈비이다. 기준범주가 바뀌어도 적합된 범주확률은 같다.

Model : The baseline-category logits are modeled by:

\(\displaystyle \log\left(\frac{\pi_j}{\pi_c}\right) = \alpha_j + \beta_j x, \quad j = 1,\cdots,c-1\)

when the last category\((c)\) is the base line.

We can calculate \(\pi_j\) from the above model,

\(\displaystyle \pi_j = \frac{\text{exp}(\alpha_j + \beta_j x)}{\sum_{h=1}^c \text{exp}(\alpha_h + \beta_h x)}\)

with \(\alpha_c = \beta_c = 0.\)

Checking multinomial model goodness of fit

다항모형의 deviance는 관측 셀도수와 적합 셀도수를 포화모형과 비교한 값이다. 희소한 셀이 많으면 카이제곱 근사가 불안정할 수 있다. 이때는 표준화 잔차와 모형 간 비교를 함께 확인한다.

As in the case of binary data, The deviance has the form

\(G^2 = 2\sum\text{observed}[\log(\text{observed}/\text{fitted})]\)

\(\log\left(\frac{\pi_j}{\pi_3}\right) = \alpha_j + \beta_j^G x_1 + \beta_j^R x_2, \quad j = 1,2.\)

Cumulative logit models for ordinal responses

각 누적로짓은 반응을 \((Y\le j)\)와 \((Y>j)\)로 이분한 로지스틱 회귀로 볼 수 있다. 비례오즈 모형은 모든 절단점에서 같은 기울기 \(\beta\)를 사용하며, \(\exp(\beta)\)가 공통 누적 오즈비이다. 해석 전에 범주 순서와 로짓 방향을 확인해야 한다.

When reponse categories are ordered, the logits can utilize the ordering. This results in models that have simpler interpretations, less parameters and potentially greater power than baseline-category logit models.

  • A cumulative probability : \(\displaystyle P(Y\le j) = \sum_{h=1}^j \pi_h, \quad j=1,\cdots,c\)

  • The logit of the cumulative probabilities : \(\displaystyle \text{logit}[P(Y\le j)] = \log\left[ \frac{P(Y\le j)}{1-P(Y\le j)} \right] = \log\left[\frac{\pi_1 + \cdots + \pi_j}{\pi_{j+1} + \cdots + \pi_c} \right]\)

  • Model : \(\text{logit}[P(Y\le j)] = \alpha_j + \beta_j x, \quad j = 1,\cdots,c-1\)

The cumulative logit models explain log-odds of two cumulative probabilities(\(j\) or less than \(j\) vs higher than \(j\)).

If \(\beta_j = \beta\) for all \(j\)’s, the model is called proportional odds cumulative logit model.

Inference about cumulative logit model parameters

The pros and cons of the baseline-category logit model(with treating \(x\) as nominal)

  • advantage : not assuming as much about the model structure, such as linearity for the family income effect.
  • disadvantage : lower power because the null hypothesis has more parameters.

If there exists a linearity for the family income effect, it would be more desirable to use a cumulative logit model for detecting the significance of the effects.


Extensions

Cumulative logit model without proportional odds

비(非)비례오즈 모형은 절단점마다 다른 기울기를 허용하지만 모수가 빠르게 늘어난다. 두 모형이 중첩되면 deviance 차이로 비례오즈 제약을 검정할 수 있다. 복잡한 모형이 유의하게 개선되지 않았다는 결과는 단순모형이 자료와 양립한다는 뜻이다.

The cumulative logit model(w/ proportional odds) assumes the distribution of \(Y\) is shifted up or down by any setting of the explanatory variables.

We now consider the more general cumulative logit model that has separate effects(capturing variability for multiple explanatory variables) for the different cumulative probabilities.

When we can fit this model, an alternative goodness-of-fit test of the model with proportional odds structure is the likelihood-ratio test comparing it to more complex model by the change in deviance.

Paired-category logit modeling of ordinal response

1. Adjacent-categories logit model

인접범주 로짓은 이웃한 두 범주를 비교하며 \(\exp(\beta)\)는 국소 오즈비이다. 공통 기울기 모형은 한 단계 이동 효과가 척도 전반에서 같다고 가정한다. 범주의 순서가 바뀌면 모형의 의미도 달라진다.

Cumulative logit models for ordinal responses use the entire response scale in forming each logit. Alternative logits for ordered categories use pairs of categories.

  • Adjacent-categories logits : \(\displaystyle \log\left(\frac{\pi_j}{\pi_{j+1}} \right), \quad j = 1,\cdots,c-1\)

  • Model : \(\displaystyle \log\left(\frac{\pi_j}{\pi_{j+1}} \right) = \alpha_j + \beta x, \quad j = 1,\cdots,c-1\)

2. Sequential logits model

sequential 또는 continuation-ratio 로짓은 반응이 단계적으로 진행되는 과정에 적합하다. 현재 단계에 도달한 대상이 다음 단계로 진행하는 조건부 확률을 모형화한다. 진행 방향은 실제 자료 생성과정에 맞게 정해야 한다.

  • Sequential logits : \(\log\left(\frac{\pi_1}{\pi_2 + \cdots + \pi_c} \right), \log\left(\frac{\pi_2}{\pi_3 + \cdots + \pi_c}\right), \cdots, \log\left(\frac{\pi_{c-1}}{\pi_c} \right)\)

  • They refer to a binary response that contrasts each category with a grouping of all categories from higher levels of the response scale.

[Example : Tonsil size and streptococcus]

  • Response variable : tonsil size (3 ordered outcomes : not enlarged, enlarged, greatly enlarged)
  • Explanatory variable : indicate variable whether a child is a carrier or Streptococcus pyogenes (1=yes, 0=no)
  • sequential logit model with proportional odds str : \(\log\left(\frac{\pi_1}{\pi_2 + \pi_3} \right) = \alpha_1 + \beta x ,\quad \log\left(\frac{\pi_2}{\pi_3} \right) = \alpha_2 + \beta x\)
