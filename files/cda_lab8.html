McNemar Test Comparing Marginal Proportions

McNemar 검정은 서로 다른 반응을 보인 discordant pair \(n_{12}\)와 \(n_{21}\)만 사용한다. \(n^*=n_{12}+n_{21}\)가 작으면 \(\mathrm{Bin}(n^*,1/2)\) 정확검정을, 충분히 크면 정규 또는 카이제곱 근사를 사용한다. Pearson 독립성 검정은 다른 가설을 검정한다.

For matched-pairs data with a binary response, a test of marginal homogeneity has null hypothesis

\(H_0 : P(Y_1=1) = P(Y_2=1), \text{or equivalently } H_0:\pi_{12}=\pi_{21}\)

First \(H_0\) is called marginal homogeneity and the second \(H_0\) is called symmetry across the main diagonal. In \(2\times2\) (binary matched pairs), those are equivalent.

McNemar Test : When \(H_0\) is true, we expect similar values for \(n_{12}\) and \(n_{21}\) so, for \(n^\ast=n_{12}+n_{21}\),

\[ \begin{aligned} n_{12} &\sim \operatorname{Bin}(n^\ast,1/2), && \text{when } n^\ast \le 10,\\ z &= \frac{n_{12}-n_{21}}{\sqrt{n_{12}+n_{21}}} \sim N(0,1), && \text{when } n^\ast > 10. \end{aligned} \]

Marginal Models and Subject-specific models

주변모형은 모집단 평균 반응확률을, subject-specific 모형은 개인 내 조건부 효과를 설명한다. logit 모형에서는 두 효과의 오즈비가 일반적으로 같지 않다. GEE는 id로 군집을 지정하고 robust 표준오차로 군집 내 상관을 반영한다.

Marginal Models : Previous section can be considered as by-products of model-fitting.

\(P(Y_1=1)=\alpha+\delta,\;P(Y_2=1)=\alpha\) or\ \(P(Y_t=1)=\alpha+\delta x_t\)

Link functions could be identity link, logit link(\(\text{logit}[P(Y_t=1)]=\alpha+\delta x_t\)), and etc.

Comparing Proportions for Nominal Matched-Pairs Responses

범주가 \(c>2\)인 명목형 짝자료에서 주변동질성은 두 시점의 범주별 주변확률이 모두 같다는 가설이다. baseline-category marginal model에서는 \(c-1\)개의 시점효과를 동시에 검정한다.

Outcome categories are now generalized to \(c>2\). Marginal homogeneity is defined as

\(P(Y_1=i) = P(Y_2=i)\text{ for } i=1,\cdots,c\)

For nominal-scale responses, baseline-category logit models has been introduced in Ch.6. For matched pairs, the relevant marginal model is:

\(\log\left[\dfrac{P(Y_1=j)}{P(Y_1=c)}\right]=\alpha_j+\beta_j,\text{ and}\;\log\left[\dfrac{P(Y_2=j)}{P(Y_2=c)}\right]=\alpha_j,\;\text{for }j=1,\cdots,c-1\)

and the test of marginal homogeneity has null hypothesis

\(H_0 : \beta_1=\beta_2=\cdots=\beta_{c-1}=0\).

Similarly, use GEE approach and functions.

Symmetry and Quasi-Symmetry Models for Square Contingency Tables

대칭모형 \(\pi_{ij}=\pi_{ji}\)는 두 방향의 이동확률이 같다는 조건이며 주변동질성을 함의한다. 준대칭모형은 주변차이를 허용하면서 연관구조의 대칭성은 유지한다. 준대칭이 적절하면 두 모형의 적합도 차이로 주변동질성을 검정할 수 있다.

Rather than testing the marginal homogeneity, we can test symmetry or quasi-symmetry conditions.

  • Symmetry: \(\pi_{ij}=\pi_{ji},\;\forall i,j\text{ or equivalently, } \log(\pi_{ij}/\pi_{ji}) = 0\;\forall i,j\)
  • Quasi-symmetry:\(\log(\pi_{ij}/\pi_{ji}) = \beta_i-\beta_j;\forall i,j\), To test a quasi-symmetry condition, note that one parameter is being redundant: we set \(\beta_1\)=0 or \(\beta_c=0\) and also have to set up \(c\) artificial explanatory variables with coefficients 1 and -1.

Comparing Proportions for Ordinal Matched-Pairs Responses

순서형 짝자료에서는 한 시점의 반응분포가 다른 시점보다 전반적으로 높거나 낮은지를 누적로짓 효과 하나로 표현할 수 있다. 비례오즈 구조가 적절하면 명목형 방법보다 적은 자유도를 사용한다. 계수의 방향은 범주 순서와 누적확률 정의에 따라 달라진다.

For ordinal-scale responses, cumulative logit models has been introduced in Ch.6. For matched pairs, the relevant marginal model is:

\(\text{logit}[P(Y_1\leq j)]=\alpha_j+\beta,\; \text{logit}[P(Y_2\leq j)]=\alpha_j,\;\text{for }j=1,\cdots,c.\)

Note that it has a proportional odds structure as in Section 6.2

An Ordinal Quasi-Symmetry Model

순서형 준대칭모형은 반대방향 셀확률의 로그비가 범주점수 차이에 비례한다고 가정한다. 점수 선택이 결과에 영향을 주므로 척도에 맞는 점수를 사용하고 일반 준대칭모형과 적합도를 비교한다.

Rather than using nominal-scale quasi-symmetry model, if \(\{\beta_i\}\) in the model have a linear trend when the categories are ordinal, let \(u_1\leq u_2\leq u_c\) denote ordered scores for both the row and column categories.

  • The ordinal quasi-symmetry model is \(\log(\pi_{ij}/\pi_{ji}) = \beta(u_j-u_i)\)
  • This has the form of the usual logistic regression model, \(\text{logit}[\pi(x)]=0+\beta*x, \;x=\mu_i-\mu_j\)

To fit the model, need a logistic model with intercept forced to equal 0 and with value of the predictor \(x\) equal to \(u_j-u_i\).

Measuring Agreement Between Two Observers

강한 연관성이 반드시 높은 일치를 뜻하지는 않는다. 한 평가자가 항상 더 높게 평가하면 연관성은 강해도 정확한 일치는 낮을 수 있다. quasi-independence 모형은 주변분포 차이를 허용하면서 주대각선의 추가 일치효과를 모형화한다.

One way of evaluating agreement uses the loglinear model of independence:

\(\log \mu_{ij} = \lambda + \lambda_i^X+ \lambda_j^Y\)

This model provides a baseline model, showing the degree of agreement expected if no association existed between the ratings, i.e. Poorly-fitting occurs if there is even only mild agreement.

  • A more useful loglinear model adds a term describing agreement beyond that expected under independence, called quasi-independence model:

    \(\log \mu_{ij} = \lambda + \lambda_i^X+ \lambda_j^Y+\delta_iI(i=j)\)

Cohen’s Kappa

Cohen의 \(\kappa\)는 관측 일치율에서 우연 일치율을 뺀 뒤 가능한 최대 개선폭으로 나눈 값이다. \(\kappa=0\)은 우연 수준, \(\kappa=1\)은 완전일치를 뜻한다. 주변분포가 치우치면 값이 작아질 수 있으므로 원 분할표와 일치율을 함께 확인한다.

  • Cohen’s kappa is a single summary index that describes strength of agreement:

    \(\kappa= \dfrac{\sum_i\pi_{ii}-\sum_i\pi_{i+}\pi_{+i}}{1-\sum_i\pi_{i+}\pi_{+i}}\)
