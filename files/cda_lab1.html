1. Introduction

Statistical Distributions

R의 분포 함수는 접두사로 구분한다. d*는 한 점의 확률질량 또는 밀도, p*는 누적확률 \(P(X\le x)\), q*는 분위수, r*는 난수 생성 함수이다. 이산분포에서 d*는 정확한 확률질량을 반환하며, lower.tail = FALSE는 오른쪽 꼬리확률을 계산한다.

Basic Asymptotic properties

대수의 법칙(The Law of Large Numbers)은 표본비율 \(\hat\pi\)가 표본크기가 커질수록 참비율 \(\pi\)에 가까워짐을 뜻한다. 중심극한정리(Central Limit Theorem, CLT)는 \(\sqrt{n}(\hat\pi-\pi)/\sqrt{\pi(1-\pi)}\)의 분포가 표준정규분포에 가까워짐을 뜻한다. 이항분포의 정규근사는 보통 \(n\pi\)와 \(n(1-\pi)\)가 모두 약 5 이상일 때 안정적이다.

There are some basic large-sample(or asymptotic) properties essential in statistical inferences.

  • The Law of Large numbers
    Suppose \(X_1, X_2, \cdots, X_n \sim (\mu, \sigma^2)\).
    Then \(\bar{X}=\frac{1}{n}\sum\limits_{i=1}^n X_i \xrightarrow{p}\mu\).
p<-0.7
phat<-0
n<-0
for(i in 1:5){
  n[i]<-10^i
  X<-rbinom(n[i],1,p)
  phat[i]<-sum(X)/n[i]
}
plot(log10(n),phat, ylim=c(0.3,1));abline(h=0.7, lty=2, col='red')

for(j in 1:20){
  for(i in 1:5){
    n[i]<-10^i
    X<-rbinom(n[i],1,p)
    phat[i]<-sum(X)/n[i]
    points(phat)
  }
}
  • Central Limit Theorem
    Suppose \(X_1, X_2, \cdots, X_n \sim (\mu, \sigma^2)\).
    Then \(\frac{\sqrt{n}(\bar{X}-\mu)}{\sigma} \xrightarrow{d}N(0,1)\).
    Especially, binomial distribution \(B(n,p)\) can be approximated by \(N(np,npq)\) when both \(np, nq\) are large.
p<-0.5
n<-c(5,10,30,100,300,1000)
##x<-seq(from=0, to=n, by=0.1)
x<-sapply(n,seq,from=0,by=1)
par(mfrow=c(2,3))
mu<-0;sd<-0
for(i in 1:6){
  mu<-n[i]*p
  sd<-sqrt(n[i]*p*(1-p))
  norpdf<-dnorm(x[[i]],mean=mu,sd)
  normax<-max(norpdf)
  binpdf<-dbinom(x[[i]],n[i],p)
  plot(x[[i]],binpdf,type="l", main=n[i], xlab='x', ylab='density',ylim=c(0,normax))
  lines(x[[i]],norpdf, col='red',lty=2)
}

If \(p\) gets closer to 0 or 1, then we need larger \(n\) to obtain nice approximation.

\(Y\sim\mathrm{Bin}(n,\pi)\)에서 최대우도추정량(MLE)은 \(\hat\pi=Y/n\)이다. Wald 방법은 표본이 작거나 비율이 0 또는 1에 가까울 때 부정확할 수 있으며, 신뢰구간이 \([0,1]\)을 벗어나기도 한다. prop.test(..., correct = FALSE)의 score 계열 추론은 이러한 상황에서 대체로 더 안정적이다.

Mid P-value

이산형 확률분포의 정확검정(exact test)은 실제 제1종 오류확률이 미리 정한 유의수준 \(\alpha\)보다 작아지는 보수성을 보일 수 있다. mid-\(P\)는 관측 결과의 확률을 절반만 포함해 보수성을 줄이지만, 사용한 \(P\)값의 정의를 결과에 명시해야 한다.

2. Contingency Table

Difference of Proportions

위험차 \(\pi_1-\pi_2\)는 두 확률의 차이, 상대위험 \(\pi_1/\pi_2\)는 확률의 배수, 오즈비는 오즈의 배수이다. 독립의 기준값은 각각 0, 1, 1이다. 사건이 드물면 오즈비와 상대위험이 비슷하며, 오즈비 신뢰구간은 \(\log(OR)\) 척도에서 계산한 뒤 지수변환한다.

  • For two independent binomial samples with sample sized \(n_1\) and \(n_2\).

  • The estimated standard error of \(\hat{\pi}_1-\hat{\pi}_2\) is

    \(\displaystyle SE = \sqrt{\frac{\hat{\pi}_1(1-\hat{\pi}_1)}{n_1} + \frac{\hat{\pi}_2(1-\hat{\pi}_2)}{n_2}}\)

  • \(100(1-\alpha)\%\) Wald C.I. for \(\pi_1 - \pi_2\) is

    \(\displaystyle (\hat{\pi}_1-\hat{\pi}_2) \pm Z_{\alpha/2}SE\)

  • Risk Difference : \(Difference\;of\;Proportions=\pi_1-\pi_2\)

  • Relative risk (RR) : \(\displaystyle RR = \frac{\pi_1}{\pi_2}\)

  • Odds : \(\displaystyle \frac{\pi}{1-\pi}\)

  • Odds Ratio (OR) : \(\displaystyle OR = \frac{\pi_1/(1-\pi_1)}{\pi_2/(1-\pi_2)}\)

  • The asymptotic standard error for the log odds ratio (OR) :

    \(\displaystyle SE_{OR} = \sqrt{\frac{1}{n_{11}} + \frac{1}{n_{12}} + \frac{1}{n_{21}}+ \frac{1}{n_{22}}}\)

  • Wald \(100(1-\alpha)\%\) C.I. for \(\log(OR)\) :

    \(\log(OR) \pm z_{\alpha/2}SE_{OR}\)
