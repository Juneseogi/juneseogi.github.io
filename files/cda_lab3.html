Ungrouped and Grouped Binary Data

같은 설명변수 값을 가진 0/1 관측을 성공횟수와 시행횟수로 묶어도 최대우도추정치와 표준오차는 같다. grouped 자료의 weights = n은 이항 시행횟수이며, 복합표본조사의 표본가중치와는 다르다.

For binary \(Y\) and categorical variable \(X\), you may encounter two types of binary data.

  • Ungrouped: each row represents a person/unit. The response value is whether 0 or 1.
  • Grouped: each row represents a category. The response value is the number of successes within the category.

Logistic Regression

\(\beta>0\)이면 \(x\)가 커질수록 성공확률이 증가하고, \(\exp(\beta)\)는 \(x\) 1단위 증가에 대한 오즈비이다. 로지스틱 확률곡선은 S자형이므로 확률 변화량은 일정하지 않다. 절편 해석이 어렵다면 \(x\)를 평균 중심화(centering)할 수 있다.

\(\displaystyle logit(\pi(x)) =\log\left(\frac{\pi}{1-\pi}\right) = \alpha + \beta x\)
\(\pi(x) = P(Y=1 | X=x) = \frac{exp(\alpha+\beta x)}{1+exp(\alpha+\beta x)}\)
\(\frac{\pi(x)}{1-\pi(x)} = e^{\alpha}(e^{\beta})^x\)

Statistical inference for logistic regression

\(\beta\)의 신뢰구간을 지수변환하면 오즈비 \(\exp(\beta)\)의 신뢰구간이 된다. 작은 표본, 극단적인 적합확률, 분리 현상에서는 Wald 구간보다 profile likelihood 구간이 더 안정적일 수 있다.

  • A Wald C.I. for the effect(\(\beta\)) with a single explanatory variable : \(\hat{\beta} \pm z_{\alpha/2}SE\).
  • A profile likelihood C.I. is obtained from \[\displaystyle 2\log \left(\frac{L(\hat{\alpha}, \hat{\beta})}{L(\hat{\alpha}(\beta), \beta)} \right) < \chi^2_{df, 1-\alpha}\] where \(L(\hat{\alpha}(\beta), \beta)\) is the profile likelihood of \(\beta\) and \(L(\hat{\alpha}, \hat{\beta})\) is the likelihood maximized at the estimated \((\hat{\alpha}, \hat{\beta})\).

For the summary of fit, \(\hat{\beta} = 0.497, SE = 0.102\), so the Wald C.I. for \(\beta\) is \(0.497 \pm 1.96(0.102) = (0.298, 0.697).\)

Fitted values and C.I. for probabilities

확률의 신뢰구간은 선형예측자 \(\eta=\alpha+\beta x\)의 구간을 구한 뒤 inverse-logit을 적용한다. 변환된 끝점은 항상 0과 1 사이에 놓인다. 모형 기반 확률은 전체 자료를 이용해 관계를 평활화(smoothing)한다.

The estimated probability can be obtained by

\(\displaystyle \hat{P}(Y=1) = \frac{exp(\hat{\alpha} + \hat{\beta}x)}{1+exp(\hat{\alpha} + \hat{\beta}x)}\)

Construction of a C.I. for \(P(Y=1)\)

  • Finding a C.I. for the linear predictor value \(\alpha + \beta x\)
  • Applying the \(exp()/[1+exp()]\) transform to the endpoints (lower bound, upper bound) (Note that this function is one-to-one.)
pred.prob <- fitted(fit) # ML fitted value estimate of P(Y=1)
lp <- predict(fit, se.fit = T) # linear predictor, at given data x
LB <- lp$fit - 1.96*lp$se.fit # Wald confidence bounds for linear predictor
UB <- lp$fit + 1.96*lp$se.fit
LB.p <- exp(LB)/(1+exp(LB)) # confidence bounds for P(Y=1)
UB.p <- exp(UB)/(1+exp(UB))
cbind(Crabs$width, pred.prob, LB.p, UB.p)

Logistic regression model with categorical explanatory variable

범주형 설명변수는 기준범주와 지시변수로 표현한다. 각 계수는 다른 변수를 고정했을 때 해당 범주와 기준범주의 로그오즈 차이이며, 지수변환하면 조건부 오즈비가 된다. 해석 전에 levels()와 실제 코딩을 확인해야 한다.

[Example : Survey about marijuana use]

Multiple logistic regression

다중 로지스틱 회귀의 \(\beta_j\)는 나머지 설명변수를 고정한 부분효과이다. 설명변수끼리 강하게 연관되면 개별 계수의 표준오차가 커질 수 있다. 상호작용이 없는 주효과 모형은 조건부 오즈비가 다른 변수의 수준에 따라 변하지 않는다고 가정한다.

\(\displaystyle logit(\pi(x)) = \log\left(\frac{\pi}{1-\pi}\right) = \alpha + \beta_1 x_1+\cdots+\beta_p x_p\)

\(\beta_j\) refers to the effect of \(x_j\) on the log odds that \(Y=1\) controlling the other \(x\)’s.

[Example : Horseshoe Crabs]

  • \(\pi(x)\) : probability of a female crab has any other satellites.
  • Explanatory variable : female crab’s shell width(cm) and color(1=medium light, 2=medium, 3=medium dark, 4=dark).

The color variable is discrete variable which treated as a nomial-scale factor, so we construct our model by using three indicator variables as follows:

\(\mathbf{Model1} : logit(P(Y=1)) = \alpha + \beta_1 x + \beta_2 c_2+ \beta_3 c_3+ \beta_4 c_4\)

where \(x :\) the shell width and \(c_2 = 1\) for color is medium, \(c_3 = 1\) for color is medium dark, \(c_4 = 1\) for color is dark, 0 otherwise.

Model comparison

우도비 모형비교는 축소모형이 전체모형에 포함되는 중첩모형에 사용한다. 검정통계량은 deviance 차이이고 자유도는 추가된 모수의 수이다. 중첩되지 않은 모형은 AIC나 예측성능으로 비교한다.

To test certain terms are needed in the model, we can compare the deviance values for that model and for the simpler model without those terms.

For example, test whether color contributes significantly to model, i.e.,

\(H_0: \beta_2 = \beta_3=\beta_4 = 0\)

The likelihood ratio statistic is \(2(L_1-L_0)\)
where
\(L_1\) is the maximum log-likelihood for the full model, and
\(L_0\) is the maximum log-likelihood for model under \(H_0\).

Marginal effects and their average

로지스틱 모형의 한계효과는 현재의 \(x\)와 예측확률에 따라 달라진다. 평균한계효과는 각 관측값에서 계산한 변화량의 평균이며, 모든 변수를 평균값에 고정한 효과와는 다르다.

  • Average marginal effect : average of the rate of change at the \(n\) sample values of the (continuous) explanatory variables.
  • Discrete change : average of difference between the estimate of \(P(Y=1)\) for the two categories for a binary explanatory variable.
