Chapter 2

Odds Ratio

오즈 \(\pi/(1-\pi)\)는 성공확률과 실패확률의 비이다. \(2\times2\) 표에서 \(OR=1\)은 독립을 뜻하며, 행이나 열의 순서를 하나만 바꾸면 오즈비는 역수가 된다. 오즈비는 표를 전치(transpose)해도 같으므로 환자-대조군 연구에서도 추정할 수 있고, 신뢰구간은 \(\log(OR)\)에서 계산한 뒤 exp()로 되돌린다.

  • Odds : \(\displaystyle \frac{\pi}{1-\pi}\)
  • Odds Ratio (OR) : \(\displaystyle OR = \frac{\pi_1/(1-\pi_1)}{\pi_2/(1-\pi_2)}\)
  • The asymptotic standard error for the log odds ratio (OR) :

    \(\displaystyle SE_{OR} = \sqrt{\frac{1}{n_{11}} + \frac{1}{n_{12}} + \frac{1}{n_{21}}+ \frac{1}{n_{22}}}\)

  • Wald \(100(1-\alpha)\%\) C.I. for \(\log(OR)\) :

    \(\log(OR) \pm z_{\alpha/2}SE_{OR}\)

  • oddsratio() function
    • oddsratio(c(n11, n12, n21, n22), conf.level, correct)

Independent Test in Two-way tables

독립모형의 기대도수는 \(\hat\mu_{ij}=n_{i+}n_{+j}/n\)이다. Pearson \(\chi^2\)와 우도비(Likelihood ratio) \(G^2\)는 표 전체의 독립성을 검정하며, 표본이 충분히 크면 비슷한 결과를 낸다. 유의한 결과가 나오면 표준화 잔차로 어느 셀이 독립모형에서 벗어나는지 확인한다.

There are two ways to perform it, chi-squared test and likelihood ratio test.


\(\displaystyle \boldsymbol{H_0 : \pi_{ij} = \pi_{i+}\pi_{+j}}\) for all \(i\) and \(j\)


  • (Pearson) Chi-Squared test
    • \(\displaystyle \chi^2 = \sum\frac{(n_{ij}-\mu_{ij})^2}{\mu_{ij}}\)
  • Likelihood Ratio Statistic
    • \(\displaystyle G^2 = 2\sum n_{ij}\log(\frac{n_{ij}}{\mu_{ij}})\)
  • larger values provide stronger evidence against \(H_0\).
  • \(df = (r-1)(c-1)\) for \(r\times c\) contingency tables.
  • Standardized residual :

    \(\displaystyle \frac{n_{ij}-\hat{\mu}_{ij}}{\sqrt{\hat{\mu}_{ij}(1-\hat{\pi}_{i+})(1-\hat{\pi}_{+j})}} = \frac{n(\hat{\pi}_{ij}-\hat{\pi}_{i+}\hat{\pi}_{+j})}{\sqrt{n\hat{\pi}_{i+}\hat{\pi}_{+j}(1-\hat{\pi}_{i+})(1-\hat{\pi}_{+j})}}\)

Testing Independence for Ordinal Data

일반적인 \(\chi^2\)와 \(G^2\) 검정은 범주의 순서를 사용하지 않고 \((r-1)(c-1)\) 자유도를 쓴다. \(M^2=(n-1)R^2\) 검정은 범주점수를 이용해 단조로운 선형추세를 1 자유도로 검정한다. 결과는 점수 선택에 영향을 받으므로 범주 간 간격을 반영하는 점수가 필요하다.

In the case with ordinal row and/or columns variable, new test statistics reflects the ordering need to be implemented.

  • Let \(u_1 \le u_2 \le \cdots \le u_r\) denote scores for the rows.
  • Let \(v_1 \le v_2 \le \cdots \le v_c\) denote scores for the columns.
  • Pearson sample correlation with scores : \(\displaystyle R = \frac{\sum_{i}\sum_{j}(u_i-\bar{u})(v_j-\bar{v})\hat{\pi}_{ij}}{\sqrt{[\sum_i (u_i - \bar{u})^2\hat{\pi}_{i+}][\sum_j (v_j - \bar{v})^2\hat{\pi}_{+j}]}}\) where \(\bar{u} = \sum_{i}u_i\hat{\pi}_{i+}\) and \(\bar{v} = \sum_j v_j\hat{\pi}_{+j}\)

For testing \(H_0 : \rho = 0\) vs \(H_a : \rho \not= 0\)

  • test statistics : \(M^2 = (n-1)R^2\)
  • larger values of \(M^2\) provide more evidence against the independence model.

Exact Inference for Small Samples - Fisher’s exact test

Fisher의 정확검정은 행합과 열합을 고정한 조건부 분포를 사용하며, 한 셀의 도수는 초기하분포(Multinomial distribution)를 따른다. 기대도수가 작은 \(2\times2\) 표에서도 카이제곱 근사 없이 계산할 수 있으며, mid-\(P\)는 일반 exact 검정의 보수성을 줄이는 방법이다.

When \(n\) is small or the data are unbalanced, frequentist inference can use exact distributions rather than large-sample approximations.

Logistic Regression

로지스틱 회귀는 이항분포, 선형예측자, logit 연결함수로 구성된 GLM이다. 계수 \(\beta\)는 \(x\)가 1 증가할 때의 로그오즈 변화이며, \(\exp(\beta)\)는 오즈비이다. probit 모형도 S자형 확률곡선을 사용하지만 계수의 척도는 다르다.

It is a special case of a GLM for binary data, with these components.

  • Random component : \(Y \sim Bin(n, \pi)\)
  • Linear predictor : \(\alpha + \sum_{i=1}^p \beta_i x_i\)
  • Link function : \(\eta = logit(\pi) = \log(\pi(x)/(1-\pi(x)))\)

Logistic regression models are often called logit models.
On the other hand, there is another model called the probit model.

  • Probit model : \(\pi(x) = \Phi(\alpha + \beta x)\), where \(\Phi\) is the CDF of standard normal distribution.

Poisson Regression

포아송 회귀의 로그 연결은 평균을 항상 양수로 만들며, \(x\)가 1 증가할 때 평균도수는 \(\exp(\beta)\)배가 된다. 기본 모형은 \(\operatorname{Var}(Y)=E(Y)\)를 가정한다. 과산포(Overdispersion)가 있으면 표준오차가 작게 추정될 수 있으므로 deviance, Pearson 통계량, 잔차를 확인한다.

This also a special case of a GLM for count response variables.

  • Random component : \(Y \sim Poisson(\mu)\)
  • Linear predictor : \(\alpha + \sum_{i=1}^p \beta_i x_i\)
  • Link function : \(\eta = \log(\mu)\)

Statistical inference and model checking

Wald 검정은 최대우도추정치에서, score 검정은 귀무가설 아래에서 표준오차를 계산한다. 우도비 검정은 제한모형과 전체모형의 최대우도를 비교하며, 작은 표본이나 희소자료에서는 Wald 방법이 가장 불안정할 수 있다.
