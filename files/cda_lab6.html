In this chapter, we focus on Loglinear models, which can be seen as generalized linear models for count data.

Loglinear model

로그선형 모형은 분할표의 셀도수 \(n_{ij}\)를 포아송 평균 \(\mu_{ij}\)로 모형화하며 반응변수와 설명변수를 구분하지 않는다. 두 변수의 독립모형은 주효과만 포함하고 \(XY\) 상호작용을 제외한다. 표준적인 조건에서는 주변합이 고정된 표본설계도 같은 연관성 추론을 준다.

For an \(r\times c\) contingency table on a row variable \(X\) and a column variable \(Y\). From the independence assumption, \(\pi_{ij} = \pi_{i+}\pi_{+j}\),

Model :

\(\log{\mu_{ij}} = \log n + \log{\pi_{i+}} + \log{\pi_{+j}} = \lambda + \lambda_i^{X} + \lambda_j^{Y}\)

  • \(\lambda\) : overall effect (\(=\log{\sum_{i,j} \mu_{ij}}\))
  • \(\lambda_i^{X}\) : row \(i\) effect of variable \(X\), the larger the value of \(\lambda_i^{X}\), the larger each expected frequency is in row \(i\).
  • \(\lambda_j^{Y}\) : column effect of variable \(Y\)

The null hypothesis of independence is equivalently the hypothesis that this loglinear model holds.

A loglinear model for contingency tables does not distinguish between response and explanatory classification variables. The above model treats both \(X\) and \(Y\) as reponses, modeling the cell counts.

  • \(X\) : happiness (not too happy, pretty happy, very happy)

Saturated models for two-way contingency tables

포화모형은 가능한 모든 상호작용을 포함해 관측 셀도수를 정확히 재현한다. 따라서 deviance와 잔차 자유도는 0이며, 축소모형을 비교하는 기준이 된다. \(XY\) 상호작용이 모두 0이면 두 변수는 독립이다.

Saturated Loglinear Model :

\(\log{\mu_{ij}} = \lambda + \lambda_i^X + \lambda_j^Y + \lambda_{ij}^{XY}\)

There is direct relationships between log odds ratios and the \(\lambda_{ij}^{XY}\). If \(\lambda_{ij}^{XY} = 0\), the log odds ratio is zero.

Two-factor parameters describe conditional associations

세 변수 모형 \((AC,AM,CM)\)은 모든 이원 상호작용을 포함하고 삼원 상호작용 \(ACM\)은 제외한다. 이는 조건부 오즈비가 세 번째 변수의 모든 수준에서 같다는 동질연관 모형이다. 삼원 상호작용은 조건부 연관성이 층에 따라 달라짐을 뜻한다.

Inference for loglinear models

특정 조건부 연관성은 해당 이원 상호작용을 포함한 모형과 제거한 축소모형을 비교해 검정한다. deviance 증가량은 두 모형의 모수 수 차이를 자유도로 하는 우도비 통계량이다. 상위차수 항을 포함할 때는 관련 하위차수 항도 유지한다.

Significance tests about conditional associations

To test a conditional association in a model, compare the model to the simpler model not containing that association.

fit <- glm(count ~ A + C + M + A:C + A:M + C:M, family = poisson, data = Drugs)
fit2 <- glm(count ~ A + C + M + A:M + C:M, family = poisson, data = Drugs)
deviance(fit); deviance(fit2)
[1] 0.3739859
[1] 187.7543
library(car)
Loading required package: carData
Anova(fit)

The LRT statistic equals \(187.75-0.37 = 187.38\) with df \(=2-1=1\, (p-value < 0.0001)\), which implies that there is a strong evidence of an AC conditional association.

Also, there is a strong evidence of both AM and CM conditional associations.


Cell standardized residuals

전역 적합도 검정이 유의하면 표준화 셀 잔차로 모형에서 벗어난 셀을 확인한다. \(|r|>2\)는 탐색적 기준이며, 개별 값보다 행·열·층에 반복되는 잔차 패턴이 중요하다.

res <- rstandard(fit, type = "pearson")
res2 <- rstandard(fit2, type = "pearson")
data.frame(A, C, M, Drugs$count, fitted(fit), res, fitted(fit2), res2)

Statistical vs Practical significance

표본크기가 매우 크면 작은 모형오차도 \(G^2\) 검정에서 유의해질 수 있다. dissimilarity index \(D\)는 적합도수를 관측도수와 일치시키기 위해 이동해야 하는 관측의 비율이다. \(P\)값과 함께 \(D\)와 잔차 패턴을 확인해야 한다.

  • Dissimilarity Index :

\(D = \sum_i \frac{|n_i - \hat{\mu}_i|}{2n} = \sum_i \frac{|p_i - \hat{\pi}_i|}{2}\)

where \(n_i = np_i,\, \hat{\mu}_i = n\cdot \hat{\pi}_i\)

\(0 \le D \le 1\), smaller values represent a better fit.

fit <- glm(count ~ G*L*S + G*I + L*I + S*I, family = poisson, data = Accidents)
sum(abs(Accidents$count - fitted(fit)))/(2*sum(Accidents$count))
[1] 0.00250735
fit2 <- glm(count ~ G*L + G*S + L*S + G*I + L*I + S*I, family = poisson, data = Accidents)
sum(abs(Accidents$count - fitted(fit2)))/(2*sum(Accidents$count))
[1] 0.008219103
  • The model (GL, GS, LS, GI, LI, SI) has \(D = 0.0082\)
  • The model (GLS, GI, LI, SI) has \(D = 0.0025\)


Loglinear - Logistic Model Connection

한 변수를 이항반응 \(Y\)로 두면 로그선형 셀평균의 차이에서 로지스틱 모형을 얻을 수 있다. 대응되는 로그선형 모형에는 \(Y\) 관련 항과 설명변수들 사이의 충분한 연관구조가 포함되어야 한다. 대응이 맞으면 반응 관련 계수와 deviance가 일치한다.

  • The logistic model does not describe relationships among explanatory variables, assuming nothing about their association structure.
  • This model corresponds to the loglinear model that contains the fullest interaction term among the explanatory variables+ associations between each explanatory and the response.
